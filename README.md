# 社团活动管理系统
## 实现功能
- 登陆和注册页(/Data/index.html): 登陆验证和注册帐号(后端带有学号格式校验)
- 管理员后台页(/Data/admin.html): 发布和删除活动,查看报名学生信息(后端带有发布日期格式校验)
- 学生页(/Data/student.html): 报名活动
## 软件架构
使用web+后端本地服务器的混合架构

## 工作原理
前端作为交互界面,通过本地网络通信向本地运行的后端程序发送POST请求,后端程序(引入mongoose库,监听网络端口)接受请求后在Data中寻找对应数据并reply,前端收到reply后进行显示

## 优势:
- 简化了图形化界面开发流程(相比Qt和electron而言)
- 具有更强的跨平台性(webview和c/cpp的可移植性)
- 将本地通信过程替换为与在线服务器通信即可成为联网的管理系统

## 缺点:
- webview性能表现劣于Qt
- 前后端进行本地通信需要考虑端口占用问题
