# サークル活動管理システム

[中文](./README.md) | [English](./README.en.md) | 日本語

サークル活動管理システムは、C 言語の授業課題プロジェクトです。Mongoose の組み込み HTTP サーバーでバックエンド API を提供し、HTML/CSS/JavaScript でフロントエンドを構築し、学生アカウント、活動情報、削除記録をローカルテキストファイルに保存します。

このプロジェクトの重点は、少ない依存関係で動作する B/S 風管理システムを作ることです。学生は登録、ログイン、活動閲覧、参加申込ができ、管理者は活動の公開、編集、削除、参加学生の確認、統計情報の確認ができます。

## 機能概要

### 学生側

- 学生番号による登録とログイン。
- 活動一覧の閲覧。
- 状態やカテゴリによる活動確認。
- 活動への参加申込。
- 申込状態の確認。

### 管理者側

- 管理者ログイン。
- 名称、カテゴリ、場所、定員、締切を含む活動公開。
- 活動情報の編集。
- 活動削除とバックアップ記録。
- 参加学生一覧の確認。
- 活動統計グラフの確認。

### バックエンド検証

- 学生番号形式の検証。
- 管理者アカウントの予約。
- 活動日付形式の検証。
- 定員制限の確認。
- 重複申込の確認。
- 期限切れ活動の状態更新。

## 技術スタック

- C
- Mongoose HTTP library
- HTML / CSS / JavaScript
- Fetch API
- ローカル TXT ファイル永続化

## クイックスタート

### コンパイル

```bash
gcc main.c mongoose.c -o activity-system
```

プラットフォームによってネットワーク関連ライブラリのリンクが必要な場合は、環境に合わせて linker flags を追加してください。

### 実行

```bash
./activity-system
```

起動後にアクセスします。

```text
http://localhost:8000
```

既定の管理者アカウントは `main.c` に定義されています。

```text
username: admin
password: admin123
```

## プロジェクト構成

```text
.
├── Data/
│   ├── activity.txt
│   ├── student.txt
│   └── trash.txt
├── frontend/
│   ├── admin.html
│   ├── index.html
│   └── student.html
├── Doc.md
├── main.c
├── mongoose.c
└── mongoose.h
```

| Path | 説明 |
| --- | --- |
| `main.c` | HTTP ルート、業務ロジック、連結リスト構造、ファイル IO |
| `mongoose.c` / `mongoose.h` | 組み込み HTTP サーバーライブラリ |
| `frontend/index.html` | ログインと登録入口 |
| `frontend/student.html` | 学生の活動閲覧と申込ページ |
| `frontend/admin.html` | 管理者ダッシュボード |
| `Data/activity.txt` | 活動情報と参加学生 |
| `Data/student.txt` | 学生アカウント情報 |
| `Data/trash.txt` | 削除活動のバックアップ記録 |
| `Doc.md` | 授業課題レポートとモジュール説明 |

## データ形式

活動データは `Data/activity.txt` に保存されます。1 行が 1 つの活動記録です。

```text
ID 名称 カテゴリ 場所 定員 状態 締切 学生番号1|学生番号2|...
```

学生データは `Data/student.txt` に保存され、各行に学生番号、名前、パスワード、電話番号、クラスが含まれます。

## API 設計

バックエンドは `http://localhost:8000` で待ち受け、URI によってリクエストを振り分けます。主な API は次の通りです。

| Endpoint | 説明 |
| --- | --- |
| `/api/login` | ログイン |
| `/api/register` | 登録 |
| `/api/add` | 管理者が活動を作成 |
| `/api/change` | 管理者が活動を編集 |
| `/api/delete` | 管理者が活動を削除 |
| `/api/enroll` | 学生が活動に申込 |
| `/api/list` | 活動一覧を取得 |

API に一致しないリクエストは、`frontend/` 配下の静的ファイルへフォールバックします。

## 設計メモ

このプロジェクトは、学生と活動データをメモリ上の連結リストで管理します。起動時に `Data/` から読み込み、操作後にテキストファイルへ書き戻します。実装がシンプルで読みやすいため、データ構造、ファイル永続化、HTTP 連携を示す授業課題に向いています。

このプロジェクトには、データベース、セッションシステム、本番レベルの権限モデルは含まれていません。C 言語の Web 化練習、Mongoose 利用例、授業課題資料として扱うのが適切です。
